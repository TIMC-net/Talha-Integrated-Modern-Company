2. What was implemented in this revision (v1.2)

  • Home H1 topical clarity — single H1 keeps TIMC large and adds “General Contractor in Saudi Arabia” as the second H1 line.
  • Image alt coverage — InternalPageHero defaults descriptive alts; ProjectGrid uses project name + location; ServiceShowcase + 404 heroes labelled; logo mark stays decorative when wordmark is present.
  • Media compression — home hero MP4 8.0→3.0 MB; about MP4 8.6→6.2 MB; projects-page-hero WebP 927→472 KB.
  • Brand string — company legal/display name normalised to title case for schema and metadata consumers.

6. Ranking expectation (honest)

These changes improve crawlability, relevance signals, and page experience for realistic local queries (contractor Jeddah, equipment rental Saudi Arabia, TIMC services). They do not guarantee #1 ranking for broad terms such as “construction company.” Ranking also depends on backlinks, competition, and ongoing content — not only on-site SEO.
