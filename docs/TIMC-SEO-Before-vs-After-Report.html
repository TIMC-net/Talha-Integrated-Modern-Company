1. One-look summary

Before SEO

  • No robots.txt / sitemap.xml
  • Several pages reused homepage title/description
  • No Open Graph / Twitter / canonical setup
  • No Organization / Service / Breadcrumb schema
  • Weak internal links to service detail pages
  • ~49 MB company profile PDF
  • Limited Jeddah / KSA keyword targeting
  • Home H1 brand-only (“TIMC”)
  • Empty alts on key heroes / project cards
  • Heavy hero/about videos

After SEO

  • Live robots.txt + sitemap.xml (GSC Success)
  • Unique titles & descriptions on key routes
  • OG, Twitter, canonicals, share image
  • JSON-LD schema across site + detail pages
  • Real /services/[slug] internal links
  • Profile PDF compressed to ~5.4 MB
  • Natural local keyword pass (meta + copy)
  • Topical H1: TIMC + contractor in Saudi Arabia
  • Descriptive image alts added
  • Videos/images compressed for faster load

6. Client takeaway

Before SEO: the new website looked modern, but Google lacked the files and page signals needed to understand and discover it properly.
After SEO: the same website is crawlable, described clearly, structured with schema, faster to download key assets, and already accepted in Search Console with a successful sitemap.
