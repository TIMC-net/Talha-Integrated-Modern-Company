1. Scope of comparison

This report compares the discarded old website (flat PHP/HTML files from the TIMC archive) with the live new website at https://www.trsco.net. It focuses on SEO-relevant differences: architecture, brand naming, metadata, indexation, structured data, mobile/performance, URL equity, and content structure — not unpaid advertising results.

2. Snapshot: old website vs new website

Old website

  • Classic PHP includes (header.php, footer.php)
  • URLs like /about-us.php, /our-services.php
  • Public brand mix: Talha Rental Services (TRS) + “Talha Constructions…” titles
  • ~11–19 public PHP/HTML pages
  • jQuery 1.7-era scripts; IE9 fallbacks
  • GTM container present
  • No robots.txt / sitemap in archive

New website

  • Next.js App Router hosted on Vercel
  • Clean URLs: /about, /services/equipment-rental
  • Public brand: TIMC / Talha Integrated Modern Company
  • Sitemap with 38 discoverable URLs (confirmed in Search Console)
  • Modern responsive UI + WebP/media optimisation
  • GA4 + Search Console verification
  • robots.txt + sitemap.xml live

5. What improved for search engines

  1. Discoverability — sitemap + robots give Google a clear crawl map (38 pages already discovered).
  2. Relevance — unique titles/descriptions + Jeddah/Saudi Arabia phrasing replace empty descriptions and TRS-era wording.
  3. Understanding — JSON-LD tells Google TIMC is a Jeddah LocalBusiness/contractor with services and breadcrumbs.
  4. Sharing — Open Graph previews work when links are shared on WhatsApp/LinkedIn/etc.
  5. Continuity — 301 redirects reduce “soft 404” loss from old indexed PHP URLs.
  6. Experience signals — mobile layout + lighter media support better engagement and Core Web Vitals potential.

7. Business impact (plain language)

  • The old site looked dated and was hard for Google to understand cleanly.
  • The new site presents TIMC as a modern Jeddah contractor with clear services and projects.
  • Search Console is already receiving the new sitemap successfully.
  • Rankings still take time; this comparison shows capability and readiness, not an overnight #1 guarantee.
